# BlueShift branding policy

**Status:** author branding rules — separate from software/hardware licensing.  
**Not** a registered-trademark certificate. Do **not** use ®.

---

## Word mark

**BlueShift™** is the project and product name used by Meinolf Amekudzi.

The current trademark claim applies to the **word mark** “BlueShift”.

Use the **™** symbol with the BlueShift word mark in prominent public-facing
locations, including:

- README title / first prominent occurrence  
- project website / documentation title  
- marketing material  
- product descriptions  

---

## Where **not** to use ™

Do **not** use ™ in technical identifiers:

| Context | Example |
| --- | --- |
| Git repository name | `BlueShift` |
| Package / project identifier | `blueshift` |
| C/C++ namespaces | `blueshift::` |
| Filenames / paths | `blueshift-logo.png`, `components/...` |
| Source identifiers | macros, strings used as machine IDs |
| URLs | `github.com/mamekudz/BlueShift` |
| BLE device names | e.g. `BlueShift Keyboard` — **no ™** unless explicitly decided later |
| Compact OLED UI chrome | may omit ™ for space/glyph limits unless decided later |

---

The graphical logo is still under development.

Its branding / trademark treatment is intentionally **UNDECIDED**.

Until the final graphical logo is approved:

- do **not** add trademark claims specifically covering the logo;  
- draft artwork under `docs/assets/blueshift-logo.png` remains a **draft**;  
- OLED mono placeholder is temporary and not a figurative mark claim.  

---

## Forbidden claims

- Do **not** write `BlueShift®`.  
- Do **not** state or imply that BlueShift is a **registered** trademark.  

---

## Licensing vs branding

Software and hardware licensing (community / commercial) are **separate** from
trademark and branding rights.

Visibility of source code or draft logo files does **not** grant rights to use
BlueShift™ as a commercial product brand unless agreed.
